AI Personalized Learning & Study Planner is a student-focused project designed to support structured learning, study planning, and progress tracking. Its supporting database backup workflow helps protect project data through local MySQL backups and Google Drive storage.

Personalized study planning

Organize subjects, topics, learning activities, and study sessions.

Learning progress

Workflows record performance and identify topics that may need more attention.

Backup and recovery

The backup utility creates MySQL dump files, checks integrity, and can upload backup files to a designated Google Drive folder using the drive.file permission.
